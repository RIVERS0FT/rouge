# Fullscreen HUD / v0.4.2

## 布局与交互

- 右上角设置按钮是战局设置入口；Esc 无弹窗时打开设置。
- 语言切换、返回战局、返回主菜单和保存入口在设置弹窗内。
- 「保存战役」切换到同一个弹窗的档案子页，保留多槽位保存/载入、覆盖、删除及 JSON 导入/导出。子页可以返回设置；关闭按钮返回战局。
- 主菜单保留独立战役档案入口，方便尚未进入战局时读档。
- 单位升级位于右侧目标面板上方；天赋保留在左下领袖像；游戏底栏及其 CSS 规则已删除，不是隐藏旧按钮。
- 国旗保留左上，画像下移至屏幕左下；省份面板独立滚动。
- 弹窗支持 Tab 焦点约束、焦点恢复和输入框内 Escape。设置不会造成后台地图误点。

## 暂停语义

`paused` 保存玩家的手动暂停意图。单人会话的有效暂停为 `paused || modal === 'settings'`，包含保存子页。关闭设置恢复原意图；加载战役按原逻辑进入运行状态。局域网只显示提示并禁用本机保存，不调用暂停接口。

## 地图铺满

Three.js 画布覆盖 100% 窗口；主界面不再显示遮黑边缘或底部横栏。镜头用米勒裁剪矩形的 cover 而不是含 HUD 留白的 fit：

`distance = min(mapHeight, mapWidth / aspect) * 0.998 / (2 * tan(verticalFov / 2))`

其中 0.998 是抵消亚像素边缘漏缝的安全余量，不改变源几何或地理尺度。窄屏会遮掉左右部分经度，超宽屏可能遮掉部分南北区域；这些地区仍可拖动查看，未移出游戏范围。

缩放上限同 cover 距离。地面视锥按相机倾角计算南北边界，再限制相机焦点，避免拖动/缩放后出现框外空白。保存目标纬向焦点，让从全球搜索到省份的动画不会丢失目的地。东西循环继续复用显示副本，模拟实体不复制。初次进入战局使用铺满窗口的战略视角；3D 按钮/搜索聚焦选中省份。

## 兼容性与验证

版本 0.4.2 仅更改界面及相机；GameState v4、earth-admin1-miller-crop-v1、存档键和联机协议保持不变。既有 v0.4/0.4.1 战役不需要迁移。

新增三项纯函数回归覆盖 cover 比例、非法参数、倾斜相机边缘约束。浏览器验收覆盖设置/保存层级、暂停恢复、键盘焦点、升级和存档读回、不同分辨率、边缘拖动；联机回归检查设置打开时 tick 继续增加、保存不可用。保留原有四条游戏/地理流程和三名领袖流程。

实际通过状态以当前提交的 CI 为准。软件渲染浏览器截图不是目标硬件性能基准。地图高程、美术、Steam/EOS、海运等未完成项不在本次范围内。
