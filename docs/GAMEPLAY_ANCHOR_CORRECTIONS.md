# 地块锚点修正（贴边城镇）

地块的城镇、名牌、行军目标点和驻军集结点都在地块中心（锚点）。2026-11-17 审计发现部分锚点贴在地块边缘：城镇跨出边界，从邻地块走来的部队会在边界外被房子挡住，名牌也落在错误位置。例如“君士坦丁”的中心在比斯克拉，紧贴东撒哈拉边界，离君士坦丁城 219 km。

**判定**：中心到其他地块陆地边界不足 1.6 地图单位（约城镇房屋加接近距离），或位于地块等面积半径最外 10% 的范围。半径不足 1.5 的极小地块（吉布提、利科马）任何位置都靠近边界，不在此列。

## 1. 主陆块取错（代码修正，51 个地块）

行政区的“主陆块”原先取几何里的第一个环，它常是小岛或飞地；标注点不在其中时，中心被挪到那块小地方。现在取含 Natural Earth 标注点的可见部分，没有时取最大可见部分。受影响的 221 个行政区全部回到自己的标注点，其中 51 个是地块锚点，例如：西澳大利亚、北领地、西北地区、萨哈（雅库特）的中心从近海小岛或北极小岛回到本土；魁北克从缅因边界回到省内；西瑞士（伯尔尼）从距边界 0.015 的飞地回到伯尔尼州；东加里曼丹、福建、浙江、江苏、北海道、克里特、科西嘉、马略卡、冲绳等同理。

## 2. 锚点修正清单（[数据](../data/gameplay-anchor-corrections.json)，25 个地块）

每条记录写明被替换的原锚点，前面任何审定层改变它都会直接报错，不会悄悄移动城镇。原始 Natural Earth 数据与各审定层输出保持不变，修正只在运行时读取。

**换成另一个成员行政区（12）**：君士坦丁 → 君士坦丁省（原比斯克拉）；索菲亚 → 索菲亚市（保留“索菲亚州”名称）；墨西哥 → 联邦区（墨西哥城，原普埃布拉）；佩奇 → 科索沃波列（普里什蒂纳旁，原佩奇，紧贴黑山边界）；伊利尔斯卡比斯特里察 → 阿伊多夫什奇纳；圣萨尔瓦多 → 圣萨尔瓦多省（原圣安娜）；科切维 → 卢布尔雅那；贝卡 → 黎巴嫩山（贝卡全境贴叙利亚边界）；阿尔及尔 → 卜利达（原杰勒法；阿尔及尔市标注点在海岸线上，房屋放不下）；乌干达 → 坎帕拉（原东北角卡阿邦）；南马达加斯加 → 上马齐亚特拉（菲亚纳兰楚阿）；瓜维亚雷 → 瓜维亚雷省（同名，原亚马孙）。

**同一行政区的中心改到首府（13）**：开伯尔-普什图 → 白沙瓦；巴达赫尚 → 法扎巴德；布雷西亚 → 布雷西亚市；克鲁日 → 克卢日-纳波卡；乞力马扎罗 → 萨梅（莫希同样贴肯尼亚边界）；海尔德兰 → 阿纳姆；乌迪内 → 乌迪内市；哈利斯科 → 瓜达拉哈拉；路易斯安那 → 巴吞鲁日；西孟加拉 → 加尔各答；东马其顿-色雷斯 → 科莫蒂尼；车里雅宾斯克 → 车里雅宾斯克市；京都 → 京都市。

修正后所有达标地块的中心距其他地块陆地至少 1.6，且不在最外 10% 范围（`tests/gameplay-anchor-corrections.test.mjs`）。
