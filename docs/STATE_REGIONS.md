# v0.5.0：州区域地块、远程调兵与地块容量

## 地图口径

世界最小管理地块改用参考数据 1.13.7 的 **State Region**，而不是底层 province 像素块，也不是按国家拆分的 state。整块归属一个玩家，整块生产与占领。玩家势力依然存在，但不代表现实国家。

固定参考仓库：STERILITZIA02/Victoria-3-lite-map-editor，提交 5138a546c6607137ed3d7797b0d1154d8006dc5f，目录 tools/vanilla_1_13_7_reference/game/map_data。

共解析 781 个参考区域，其中 106 个是海域，排除后为 **675 个陆地管理地块**。大不列颠 9 块、爱尔兰岛 4 块。全球均替换，未把其他地区保留为 Natural Earth 细行政区。国家字段、国家配色、独立国界描边、国旗和国家名均移除；地块边界统一样式，左上角换为玩家阵营徽记。地块名称偶尔与国家同名，只表示该管理区域。

## 边界转换与来源

将固定省份色块按州区域成员集合聚合，保留离岛与孔洞；仅横/纵边接触创建邻接，角点接触不算邻接。原始正交像素边在共享节点处拆分后，采用 Shapely coverage_simplify，容差 0.65 像素；简化前后覆盖拓扑均验证。邻接不因国界或玩家阵营而被拆分。

使用 8192×3616 参考栅格，按北界 74°N 和 16384:7232 比例反算米勒地理坐标，与项目已有裁剪镜头共用坐标。**这是近似地理配准，不宣称官方真实经纬度、最新游戏版本或测绘精度**。中英文界面完整，未录入中文地名使用英文回退。

data/state-regions-1.13.7.json.gz 是离线运行所需的转换边界；data/state-regions-audit.json 记录来源散列、排除数、节点数及生成文件 SHA256。npm run prepare:map 只解压并校验，不联网。手动重建：

```bash
pip install numpy==2.2.6 pillow==11.3.0 rasterio==1.4.3 shapely==2.1.2
python scripts/prepare-state-reference.py
python scripts/normalize-state-atlas.py --input artifacts/state-reference --output data
```

### 素材边界

本分支采用第三方公开的原版参考边界转换，不包含原版贴图、人物、音频、模型、高度图、国家历史、建筑或数值脚本。**公开可读取不等于独立游戏再发行授权**，也不把参考工具的 MIT 许可套用到原游戏资产；转换数据不标记为 Public Domain。独立商业发行或对外扩大分发前，应核查边界转换数据的授权，必要时使用自绘/获授权边界替换。仅地图的事实名称和尺度参考不能证明全部图形素材获得许可。

## 调兵规则

指定任何有连续陆路的目标地块。高层在地块邻接图上求路线；权威模拟逐段验证局部流场，细通道无法通行时尝试其他路线。一次下令记录最终 destination 与后续 route；单位实际移动，不瞬移、不穿海。

途经己方地块继续行军；中立或敌方地块必须击败守军并完成占领后继续。途中敌军照常交战。岛屿、飞地或低于导航网格分辨率的通道可能无路，明确拒绝，而不制造海桥。本版不新增海运、跨反经线陆军路径或拖拽据点派兵；仍是选地块后右键目标，也可在面板搜索/选择远程目标。

## 兵力容量

保留 **PROVINCE_CAP=12**，可在 src/game/content.ts 调整。该值是每个地块每个阵营的最大实际兵团数，驻军、行军中的己方兵团及交战兵团都计入；敌我分开计数，避免敌军占满一个共享容量后使进攻无法发生。

没有 PLAYER_CAP 或 MAX_UNITS；没有 90 人玩家上限，也没有 360 个全局兵团上限。每块独立生产，满员停产，有空位恢复。军费不影响基础造兵。

增援按最终地块的剩余空位裁定，预留在途名额，防止多次命令或自动生产把目标超额占满。空位不足时仅派遣可容纳数量，零空位明确提示。途中地块满员时停在边界等待；不会删除、瞬移或额外生成部队。单位移出地块之前仍占用该块容量。

渲染实例缓冲区按需倍增，不截断超出旧总量的兵团。存档验证按实际地块容量检查，不按玩家/世界总数拒绝。导入 128MiB 字节护栏用于资源安全，不是造兵规则；浏览器自身存储容量仍有限，大战役保存失败可导出 JSON。
