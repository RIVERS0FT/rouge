# 地图术语与调兵目标

| 名词 | 定义 | 代码对应 |
|---|---|---|
| 原始地块 | 原始地图数据中的地块 | `sourceMap.ts` 的 `SOURCE_MAP` |
| 行政地块 | 预处理合并原始地块后进入游戏的基础地块 | `map.ts` 的 `MAP`；每个地块独立保存归属、训练、占领和驻军账户 |
| 战略区域 | 游戏内合并行政地块形成的区域 | `GameState.grouping`；保留成员行政地块，不重新分配资源 |

未在游戏内合并时，战略区域与对应行政地块重合。

调兵目标始终是一个**行政地块**，即使它已经加入战略区域，也不会把命令目标扩大到整个战略区域。
拖动高亮描出该行政地块的外边界，保留海岸、孔洞及岛屿，排除预处理前原始地块之间的内部接缝。
箭头固定连接起始行政地块中心与目标行政地块中心。

整个己方铭牌都可作为鼠标或触屏拖动起点，轻点仍选中地块。
战略区域铭牌汇总的驻军来自各成员行政地块；拖向其中一个成员时，只有其他成员向它调兵。
单次命令仅包含下令时已有的驻军，新训练的部队留守原地，需再次下令。

只有进攻路线持续显示箭头。同路线部队合用一条箭头，进入占领或有令部队耗尽后移除；
友军增援保留拖动过程的预览，不显示持续箭头。
开始占领后，原部队的箭头不会因占领被打断而重新出现；新的进攻部队可形成新箭头。
显示状态从实际队列、部队和占领信息计算，不增加存档字段或改变调兵协议。
