# 战局身份 HUD（v0.4.1）

## 布局与交互

- 左上角：本方初始国家旗帜、双语国家名，旁边保留玩家名、阵营色和菜单入口。
- 左下角：当前本方领袖的原创矢量上半身立绘、统帅等级、玩家名、经验进度，以及可打开领袖天赋面板的按钮。
- 三名领袖分别使用铁壁统帅、机动先锋、军需总监的独立服饰、面貌与配色。画像是明确的**矢量占位美术**，不是照片、历史人物肖像或最终写实渲染。
- 省份面板在画像上方独立滚动；底部操作栏保留，地图资料文字移到画像右侧。800×600、1280×720、1440×960 有布局回归检查。小于现有应用最小窗口规格的设备不在此次验收范围。
- 画像和国旗仅在战局中出现，主菜单、房间大厅和部署弹窗不加入额外固定图块。切换语言会更新替代文本，SVG 不依赖网络、emoji 字体或第二个 WebGL 上下文。

## 国家身份的当前约定

本版本没有独立的国家选择/外交/历史年份系统。`commanderIdentity(actor)` 从地图固定出生席位 `STARTS[actor]` 查出国家，作为本方初始地区身份；**不是当前选中省份或最新占领地的国旗**。即使出生省被夺走，也不改变旗帜。

当前 4 个席位对应德国、德国、法国、波兰；两个德国席位通过玩家名和阵营色区分。使用现代国家识别旗帜，不声称是1836年的政治旗帜体系。未知席位或未配置国家显示中性的无旗标记，不擅自套用其他国家旗帜。

现有地图v4的出生点是固定的，所以这次不改变GameState/存档格式/网络协议；v0.4旧战役可直接继续。将来允许玩家选择国家或随机出生时，应把国家/初始省份标识加入权威状态和存档，不能继续按席位推断。

## 美术及来源

`LeaderBust.tsx` 为本项目原创 SVG 组件，三名军官均为虚构形象。无需外部素材、字体、密钥或肖像授权。

旗帜在 `CommanderHud.tsx` 中用矢量色块绘制，`commanderIdentity.ts` 维护颜色顺序、方向和比例；颜色为游戏屏幕显示近似值，不是印刷色彩校准。形制参考：

- 德国联邦议院： https://www.bundestag.de/en/parliament/symbols/flag
- 法国总统府： https://www.elysee.fr/en/french-presidency/the-french-flag
- 波兰政府： https://www.gov.pl/web/diplomacy/polands-day-of-the-flag

## 验证

`tests/commander-hud.test.mjs` 覆盖出生国家绑定、错误席位回退、旗帜方向/比例、经验进度、v0.4存档及LAN身份兼容。
`tests/browser/commander-hud.spec.ts` 覆盖三名领袖、真实战局显示、中英文替代文本、切换江苏后旗帜不变、天赋入口、三档窗口不重叠、保存后恢复画像。
`tests/browser/lan.spec.ts` 验证客机使用自己的机动先锋而不是房主的铁壁统帅，重连后保持。

运行：`npm test && npm run build && npm run test:e2e`。实际结果以对应提交CI为准。
