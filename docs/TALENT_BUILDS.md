# 天赋与流派构筑

流派不由系统规定。游戏里没有流派标签、羁绊加成或按流派加权的抽卡；流派只是玩家手里几张天赋之间的机制联动。策划先用组合搭出样板流派，验证能玩、调好数值；其余组合留给玩家发现。

## 设计规则

1. **统一机制词汇**：天赋只通过游戏里已有的量互相影响——占领、击杀、阵亡、驻军、行军、领土、要塞、集市、兵营、建筑、资金、生命、训练、经验。
2. **每张天赋写成「读什么 → 写什么」**：A 写出的东西被 B 读到，就形成组合。`src/game/content.ts` 中每个天赋的 `reads`/`writes` 只是设计元数据，规则不读取。
3. **连通性**（由 `tests/talent-pool.test.mjs` 强制）：
   - 每个兵种的候选池里，天赋读取的每个量都至少有一张别的天赋能产出；
   - 有条件的天赋至少与 2 张天赋相连；
   - 无条件的纯数值天赋不超过候选池的三分之一。
4. **刻意冲突**：存钱 vs 花钱（国库、战争债券 vs 募兵令、兵工厂、重抽）；吃恢复期 vs 缩短恢复期（乘胜追击 vs 重建司令部）；拆建筑 vs 靠建筑（拆解充公 vs 商路、军校）。
5. **两张成型，三四张变强**：每局 7 次选择加重抽即可凑出。

## 条件词

| 词 | 定义 |
|---|---|
| 行军中 | 有行军命令的部队，包括正在进攻或占领的部队 |
| 进攻中 | 行军目标不是自己的地块 |
| 驻守 | 没有行军命令 |
| 正在占领 | 身处行军目标地块中，且该地块不属于自己 |
| 恢复期 | 占领后的 15 天 |
| 己方领土 | 自己拥有的地块 |
| 包围 | 地块一半以上（至少 2 块）的可玩相邻地块属于同一个持有「包围歼灭」的国家 |
| 未交战 | 当天没有攻击冷却，也没有受到伤害 |
| 被围攻 | 敌军占据地块中心，或敌方占领进度大于 0 |

天赋描述中的这些词在游戏里会高亮，悬停显示定义。

## 样板流派（策划预设）

`src/game/talentBuilds.ts` 的 `SAMPLE_BUILDS`。规则不知道这些流派；它们只用于流派图鉴和 AI 的选卡目标。全部由通用天赋组成，任何兵种都能凑出。

| 流派 | 核心天赋 | 循环 | 弱点 |
|---|---|---|---|
| 要塞网 | 筑垒 + 棱堡 + 要塞学派 | 每占一块就多一座要塞，反扑的敌人在你的领土里持续掉血，击杀经验归你 | 推进慢，怕被绕开 |
| 人海滚雪球 | 强征 + 密集阵型 + 大驻军⚖ | 占领补兵，8 支以上的大部队减伤，更快占下一块 | 怕溅射，训练变慢 |
| 掠夺经济 | 以战养战⚖ + 赏金 + 夺饷 | 打仗赚双倍钱，用战利品升级兵种 | 领地收入 −40%，停战即断粮 |
| 守财奴 | 国库 + 战争债券 | 不花钱就有利息，存款越多部队越强 | 和募兵令、兵工厂、重抽冲突 |
| 闪电穿插 | 突击姿态⚖ + 围城阵线 + 包围歼灭 | 多路穿插，撤走不丢占领进度，被围地块停训且多受伤害 | 驻守时伤害 −10%，怕反推 |
| 哀兵死守 | 哀兵、民兵动员、战地医疗、内线调兵中任选 3 张 | 家门口阵亡返还训练进度，被围照样出兵，未交战回血，预备队赶得快 | 出了国境全部失效 |

玩家凑齐某套样板时，天赋窗口提示「发现流派」，并记入本浏览器的图鉴；未发现的显示为「？？？」。

## 留给玩家发现

以下组合策划已验证不会失控，但不写进游戏内任何说明：

- 拆解充公 + 筑垒：抢来的建筑先拆了换钱，空出的槽再白得一座要塞。
- 夺饷 + 战争债券：抢对手的钱，同时抬高自己的伤害。
- 强征 + 乘胜追击：新征的兵正好站在恢复期地块里，直接吃加成（与重建司令部冲突）。
- 棱堡 + 包围歼灭：被围在要塞网里的敌军既停训又持续掉血。
- 重商主义⚖ + 战争债券：多出来的收入转成伤害，抵掉 −10% 攻击。
- 营造 + 商路/军校（工兵）：驻军让建筑免费升级，越升越赚钱、越出经验。
- 袭扰 + 围城阵线（骑兵）：一边断敌方收入和训练，一边慢慢把地块磨下来。

新天赋上线前，先在交互图里检查它至少接上 2 张现有天赋，并用模拟对局确认没有意外过强的组合；发现过强时调数值，不删卡。

## 抽卡与工具

- 三选一均匀随机，只排除已获得和其他兵种的专属天赋；不按流派加权。
- 「包围歼灭」「以战养战」「工业基础」从领袖 4 级起出现，只控制节奏。
- 付费重抽时可以保留 1 张（`reroll` 命令的 `keep`），其余至少换掉 1 张。
- AI 按战役种子为每个席位固定一套样板作为目标，优先选目标卡；AI 不建造，所以避开依赖主动建造的卡（工程统筹、商路、军校、征兵局、工业基础）。不消耗战役随机数。

## 实现

- **战斗条件**：引擎每个模拟步用 `combatLanes`（`src/game/talentEffects.ts`）计算每个单位的三个战斗量，写入战斗行：第 18 位模式位（对行军中/驻守目标、近距离主目标、溅射副目标比例和数量、溅射抗性），第 30 位受到伤害的减免（上限 75%，被包围时为负），第 31 位造成伤害的加成；「内线调兵」改写第 22 位陆速。WASM 内核（`scripts/simulation-kernel.as.ts` 的 `hit()` 与溅射选择）、并行物理 Worker 和 JS 回退路径（`src/game/unitFallback.ts`）读取同一组数值，`tests/talent-combat.test.mjs` 检查两条路径结果逐位一致。
- **事件**：击杀（赏金、血战磨砺、抚恤金、哀兵）、占领（强征、筑垒、拆解充公、夺饷、以战养战）、训练（大驻军、人海战术、征兵局、募兵令、民兵动员、包围、袭扰）在 `src/game/engine.ts` 的 `finishTick` 中结算。
- **每日结算**：每 20 个模拟步（1 天）结算棱堡损耗与回血；营造每 10 天结算一次。被改变生命值的单位会标记为物理缓存脏行。
- **共享状态**：包围关系与战争债券加成在每个模拟步开始时计算一次（`talentContext`），本步所有规则都用同一份。

## 兼容

- 联机规则标识 `RULES_ID` 升到 `admin1-locked-game-regions-v42`；存档版本 `STATE_VERSION` 不变（28），现有存档照常读取。
- 旧存档中「战地医疗」「步兵防线」原先提高的最大生命，读档时截到新上限。
- 原 24 个天赋 ID 全部保留；旧存档里的家族天赋按新效果生效。
