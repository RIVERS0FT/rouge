## 当前页面证据

- 在当前对局复现南美洲的横线，以及斜穿非洲、马达加斯加并延伸到海上的细线。
- 分别关闭国界、管理地块边界、经纬网、文字和海岸线进行直接绘制对比；关闭海岸线后，异常线消失。
- 在原有渲染器中，将海岸分块转换成独立的非索引线段，保留全部端点；异常线消失。
- 抽查 8 个实际海岸分块的 GPU 顶点和索引缓冲，与 CPU 数据均一致；实际绘制模式为 `GL_LINES`、索引类型为 `UNSIGNED_INT`。此结果将问题定位到实际页面的全局 32 位索引线段绘制路径，尚不能据此断言具体显卡驱动内部原因。
- 修复后再次读取当前页面：tick 11804、7080 个单位，372 个原生线段分块均不再使用索引。地形和国界已加载，原有异常长线消失。

本机证据保存在忽略目录 `artifacts/live-map-lines/`：`current-state.json`、`direct.png`、`no-coasts.png`、`coast-diagnostics.json`、`coasts-nonindexed.png`、`fixed-metadata.json`、`fixed-current.png`。对局继续运行，前后截图并非相同 tick。

## 修改与验证

`mapGeometryTiles.ts` 对原生线段使用每块独立的成对顶点，避免全局 `Uint32` 索引线段路径。保留全部原始线段、材质、透明度和保守包围盒；陆地共享颜色属性与国家宽边界维持原实现。

- 分块单元检查覆盖超过 65535 的原始顶点编号、跨块线段、完整端点集合和包围盒。
- 本机 Edge 像素测试比较完整原始海岸和分块海岸，在两个战略视角及两个倾斜近景中，超过 2 色阶的差异像素为 0。
- 海岸阴影遮挡、重复阴影和地图缓存平移、缩放、内容更新、尺寸更新检查通过。
- 独立 Edge 测试中旧索引实现也能通过静态像素对比；原页面的逐层对比与原渲染器内替换才是本次异常及修复的直接证据。静态回归测试用于检查轮廓和像素保持一致。
- 生产构建和 TypeScript 检查通过。完整核心回归 416/417 通过，唯一失败是最大地块泛光重建的耗时保护；构建与全套测试并发结束后，独立复跑整个泛光文件 12/12 通过。未放宽耗时阈值。
