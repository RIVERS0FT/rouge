# 当前大规模对局模拟优化（2026-11-15）

本页记录第一轮结果；最新进展见[20 步/秒验收](PERFORMANCE-SIMULATION-20-2026-11-15.md)，阶段记录见[第二轮模拟优化](PERFORMANCE-SIMULATION-ROUND2-2026-11-15.md)。

同一份真实对局配对回放，单步平均 **357.2 → 256.7 ms**，减少 **28.1%**；
计算吞吐 **2.80 → 3.90 步/秒**，提升 **39.1%**。仍低于固定步长对应的每秒 20 步。
这些数值是隔离模拟计算的结果，不代表页面绘制 FPS。

## 实现

- 地块包含查询预先按高度分桶，只扫描可能与当前射线相交的边；保留原始浮点运算、
  边顺序、孔洞、裁剪范围及重叠地块的首个命中顺序，不简化几何。
- 地块空间桶使用有界数组；房屋空间桶改用数字坐标，预计算静态旋转，
  扫掠检测直接计算标量，减少字符串及临时对象。城镇静态绕行节点缓存最多 512 项，
  每次仍按当前部队的地形走廊重新检查边是否合法。
- 战斗空间桶按阵营分组，搜索敌军时跳过整组友军。属性仅在当前模拟步内复用，
  下一步重新读取升级和天赋；最近目标及溅射的距离、ID 排序规则保留。
- 碰撞约束复用相同起点的地形三角形；一旦接受移动，起点坐标改变即重新查询。
  只有短陆地线段已验证通过后才跳过重复的陆地判定。

固定步长仍为 0.05 秒，Worker 调度间隔仍为 50 ms。保留全部 AI 决策、碰撞迭代和
约束预算、海岸与房屋阻挡、部队和地图画质；存档及网络状态格式不变。

```powershell
node --experimental-strip-types scripts/profile-simulation-pair.mjs --snapshot=.cache/live-perf-sim-diagnosis-20261115-state.json --reference=.cache/sim-baseline-game/engine.ts --candidate=.cache/sim-round2-reference/engine.ts --steps=80 --output=.cache/simulation-optimization-final-20261115.json
```
