# 州区参考续合并，地图 v4

> 地图 v4 历史记录。当前版本见 [v5 州区核对](STATE_REGION_REFERENCE_1_15.md)。

v4 以原有 Natural Earth 5.1.1 的 4,596 个完整 Admin 1 要素为实际地图来源。依据仓库已有的约 675 个《维多利亚 3》1.13.7 **固定州区域**的数值重叠审计，把 8 个相邻边缘组并入各自的主组。州不按开局控制国拆分；实际合并仍保留同源国家标签及共享陆地边。这里没有使用 1.15.0 的 676 项作为几何输入，也没有新增或发布该游戏的素材、坐标或边界。

| 参考州区域 | 新并入的原地块组 |
| --- | --- |
| Guinea | GIN-5630 |
| Riga | LVA-5756 |
| Nicaragua | NIC-24 |
| Mindanao | PHL-2520 |
| Formosa | TWN-1169 |
| Uganda | UGA-3076、UGA-3105 |
| Miranda | VEN-42 |

规则：同一参考州区、同一源国家标签、真实共享陆地边、碎片目标重叠至少 25% 且领先其他候选 20 个百分点、主组重叠至少 65%；加入碎片总面积不超过主组的 10%，整个组的数值重叠保留至少 65%，相对旧审计的形状交并比最多下降 2 个百分点。多个候选或不能可靠归类的保持原样，不创造陆桥。拜科努尔→卡拉干达显式合并不再扩充。同比例下自然地理边界与历史玩法分区并不一致，例如整个现代湖北要素不能无切割地复制为两个历史湖北州区。

此调整优先收拢小碎块，不宣称提升形状交并比或复刻原版。现有 7 个被影响州区的交并比变化约 0 至下降 1.85 个百分点（旧版近似配准审计口径）。运行地块 1,162→1,154，可玩 1,158→1,150，五个守军/地块使新战役少 40 个中立守军，陆路出生点 652→648。每个地区仍按 12 容量和 1 生产速率计算；这不是对移动设备性能的承诺。

地图 ID 变为 `earth-natural-earth-admin1-511-regions-v4`，存档键前缀 `rouge.save.natural-earth-admin1.regions.v4.`，联机规则标识 `admin1-locked-game-regions-v13`。旧存档保留在原键、不覆盖或迁移，旧地图需新建战役，联机需双方更新。旧版原始边界及地形寻路数据未改。

复现：`python scripts/build-state-region-consolidation.py` 验证和生成决策表，`npm run prepare:map` 应用锁定的合并并验证连通性及原始要素覆盖，最后 `node --experimental-strip-types scripts/build-spawn-sites.mjs` 重建陆路有效出生点。输入文件散列和每组面积/交叠指标保存在决策表里。
