# ROUGE · 诸省之争 — v0.3 米勒世界地图

React + Three.js 的省份征服即时战略可玩原型。真实世界行政区以**米勒圆柱投影（Miller Cylindrical）**呈现；不是 EPSG:3857，也不声称复刻《维多利亚3》的未公开投影参数或最终美术。

## 运行

需要 Node.js 22.16 或以上版本、npm 和支持 WebGL2 的桌面浏览器。首次安装依赖需要联网；地图几何随源码提供，运行时不请求在线瓦片。

```bash
git clone --branch feat/world-miller https://github.com/RIVERS0FT/rouge.git
cd rouge
npm ci
npm test
npm run dev
```

生产构建：`npm run build && npm run preview`。
浏览器验收：`npx playwright install chromium`，然后 `npm run test:e2e`。

## 本次变更

标准球面米勒正反投影；中央经线 0°；经纬度仍是原始数据坐标。
地理范围为经度 ±180°、纬度 ±90°，两极有限，不沿用 Web Mercator 的纬度裁剪。
全球二维、近景三维、行政区选择、搜索、单位与流场统一使用新坐标。
“2D”按钮根据视口比例适配整个世界；“3D”聚焦选中省份。
地图 ID、存档命名空间和局域网地图握手同步更新，避免旧坐标混用。

## 操作与玩法

开始界面 → 单人战役 → 选择领袖和兵种 → 开始征途。
左键选省，拖动平移，滚轮缩放。先选己方省份，再右键相邻省份派兵；也可以使用省份面板的目标与派遣比例。
搜索框接受中文地名、英文地名、英文国家名和行政区编码。Space 单人暂停/继续，Esc 关闭面板。

已实现：自动造兵、共享流场行军、战斗、占领、基础 AI、胜利判定、3 领袖、4 兵种、单位增量升级、领袖三选一天赋、简中/英语、多槽位保存与 JSON 导入导出。
地图含 4,596 个源行政区要素，其中两个南极要素仅显示；各国行政层级尚未完全统一。开局战区仍在欧洲大陆。
单人由 Worker 模拟，LAN 由 Node 服务端权威模拟，固定 20 Hz。

## 局域网 2–4 人

主机运行：

```bash
npm run build
npm run lan
```

所有玩家打开同一主机提供的网页：主机用 `http://localhost:8787`，其他电脑用 `http://主机局域网IP:8787`，防火墙允许 TCP 8787。房主创建房间，其余玩家以六位房间码加入，至少两名玩家后开始。
刷新后可重返本标签页的房间。所有客户端必须与主机使用同一地图版本；旧墨卡托客户端会得到版本不兼容响应。
开发时分别运行 `npm run lan` 和 `npm run dev`，Vite 代理 API。
仅适用于可信 LAN；没有公网安全承诺、房主迁移或自动发现。

## 存档兼容

v0.3 战局为 `map=earth-admin1-miller-v1, version=3`。
新槽位前缀为 `rouge.save.earth.miller.v1.`，旧墨卡托前缀 `rouge.save.earth.v1.` 不读取、不覆盖、不删除。
旧存档不能直接导入新投影；需要回到旧版本继续游戏。**本次未实现自动坐标迁移**，不将旧兵团坐标当作新坐标加载。

## 当前边界

近景高程仍为程序化起伏，城镇和士兵仍是占位资源，尚非最终写实美术。
目前仅支持主陆块陆路行军；海运、飞地运输、跨反经线行军、分块流式加载、完整补给与迷雾尚未实现。
行军与射程仍为抽象游戏单位，不是实际公里；米勒不是等面积或保角投影，经济不按屏幕面积计算。
每方 90 编制、全局 360 兵团仍是原型限制。Steam/EOS、Electron 打包与 8 人性能目标尚未完成。
