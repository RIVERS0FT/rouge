# ROUGE · 诸省之争 — 世界地图版 v0.2

React + Three.js 省份征服原型。当前地图已替换为 **真实世界行政区 + EPSG:3857 墨卡托投影**。

## 运行

需要 Node.js 22.16+。

```sh
npm install
npm test
npm run dev
```

生产与局域网：

```sh
npm run build
npm run lan
```

所有联机玩家打开主机的 8787 端口网页。2D 返回全球视图；3D 聚焦选区；滚轮缩放、拖动平移，顶部搜索定位行政区。开局位于欧洲大陆，按真实共享陆地边界进攻。

地图含 4,596 个源行政要素，支持孔洞、离岛、中英地名和国家/省份编码搜索。**Admin-1 数据存在行政层级混用，未声称全部已归一为省级。** 南极只作背景。真实高程、海运和最终写实美术尚未实现；陆军不会跨海直线行走。

地图生成器在资源缺失时下载固定 Natural Earth 版本并验证 SHA-256；生成资源随完整构建包提供，运行时无需地图联网服务。源数据为公共领域。具体版本、来源、投影公式、性能边界与旧存档兼容说明见 [世界地图说明](docs/WORLD_MAP.md)。

新旧战役分别保存，旧架空地图存档不会被覆盖，但不能直接导入新地图。Steam/EOS 平台接入仍未实现。

# ROUGE · 诸省之争

React + Three.js 的省份征服即时战略 **可玩垂直切片**。本版本不是完整商业游戏，也没有声称 Steam / Epic 已接入。

## 运行

需要 Node.js **22.16 或以上**、npm、支持 WebGL2 的桌面浏览器。首次安装需要访问 npm。

```bash
npm install
npm test
npm run dev
```

打开终端显示的地址。主菜单 → 单人战役 → 选择领袖、兵种 → 开始征途。

生产构建与预览：

```bash
npm run build
npm run preview
```

浏览器测试（首次需安装测试浏览器）：

```bash
npx playwright install chromium
npm run test:e2e
```

直接依赖锁定到确切版本；首次 `npm install` 会生成 package-lock.json。当前交付环境不能访问 npm，未伪造一个未经解析验证的 lockfile。首次在联网环境通过 CI 后，应审核并提交生成的锁文件，改为 `npm ci`。

## 局域网 2–4 人

主机运行：

```bash
npm run build
npm run lan
```

主机打开 `http://localhost:8787`。其他玩家在同一可信局域网打开 `http://主机局域网IP:8787`（防火墙需允许 TCP 8787）。**所有人使用主机提供的网页**，而不是各自启动独立服务器。

每人先选择领袖和兵种。房主创建房间，将六位房间码告诉其他人；其他人输入房间码加入。至少两名玩家后由房主开始。刷新网页后点击“重返联机房间”可复用本标签页的席位凭证。

开发时可在两个终端分别运行 `npm run lan` 和 `npm run dev`，Vite 会代理 `/api`。没有自动局域网发现；没有房主迁移；不支持公网发布。HTTP 不加密，房间服务仅适合可信 LAN。

## 已实现

- React 开始界面、出征配置、战局 HUD、升级/天赋/存档面板。
- Three.js 连续缩放：远景平面政治地图，近景地形、城镇、树林和实例化代表性士兵。两者共享同一世界状态。
- 32 个**架空**省份，邻接由共享边界计算；省份是最小占领单位。
- 20Hz 固定步长模拟；单人在 Web Worker，局域网由 Node 服务器权威计算。
- 自动生产、相邻省份派兵、反向 Dijkstra 共享流场、实际移动、战斗、占领、获胜判定。
- 3 名领袖、4 种兵种、每局最多选择 3 种；基础步兵必选。
- 火力/生命/速度增量升级；9 项条件化领袖天赋，三选一及一次重抽。
- 单人多存档、每战役独立自动存档、上一有效修订备份、JSON 导入导出。保存随机状态和当前天赋候选，读档不洗牌。
- 简体中文 / English，语言偏好持久化。
- 基础 AI、暂停、1×/2× 单人速度；局域网模式不允许客户端暂停。
- 服务端命令归属校验、限流、席位凭证、重连快照；对其他玩家隐藏待选天赋。

## 操作

左键选省，按住左键拖动地图，滚轮缩放。先选己方省份，再右键相邻省份下令；也可在左侧面板选择目标和派遣比例。`Space` 单人暂停/继续；`Esc` 关闭面板。底部打开升级、天赋和存档。右下 `2D / 3D` 切换镜头距离，不切换模拟规则。

基础步兵每 14 秒训练一个兵团；每省驻军上限 12，本方编制上限 90。战斗结束后控制省内中心 8 秒即可占领，生产恢复期 15 秒。以上为加速验证数值，不是最终平衡。控制至少 20/32 省份保持 30 秒，或消灭全部对手获胜。

## 尚未完成

真实省级全球地图、写实 glTF 美术/动画/音效、补给系统、战争迷雾、海运、分块分层流场、严格局部避让、8 人规模优化、Electron 桌面打包、Steamworks / EOS 原生登录/邀请/跨商店联机、正式存档迁移与排位反作弊。界面中的 Steam/Epic 状态为“尚未接入”，不是可用登录入口。

局域网是服务器权威的休闲原型，**并非安全的公网竞技服务**。大部分世界状态公开，未实现迷雾过滤。断线不自动交给 AI，服务器退出将结束当前房间。单人 Worker 避免渲染帧率直接驱动规则，但浏览器仍可能限制后台标签页计时。

## 工程结构

```text
src/game/       纯规则、地图、流场、存档验证
src/platform/   Worker 会话、HTTP/SSE 会话与平台能力状态
src/render/     Three.js 场景、LOD 表现、拾取、实例化单位
src/ui/         React 界面和双语资源
server/         权威 LAN 服务与静态文件服务
tests/          核心、存档、真实 HTTP LAN 和浏览器测试
docs/           当前架构、验收状态与下一阶段计划
```

源码不包含第三方商业素材或平台密钥。使用的 npm 依赖由各自许可约束。
